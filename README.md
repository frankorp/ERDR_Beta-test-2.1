# 🛡️ ЄРДР PRO - Система з постійною базою даних

## Особливості цієї версії:
- ✅ **Постійне зберігання даних** - SQLite база даних
- ✅ **REST API** - повноцінний бекенд
- ✅ **Автентифікація** - безпечне зберігання паролів
- ✅ **Система логування** - всі дії зберігаються
- ✅ **Експорт даних** - CSV, JSON формати
- ✅ **Легка установка** - без налаштування сервера БД
